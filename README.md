# TRUSTLENS 🔍

AI-Based Website Trust Evaluation System

## 📌 Overview
TRUSTLENS analyzes suspicious websites using:
- Text Analysis (Machine Learning)
- Image Reuse Detection
- Behavioural URL Analysis
- Weighted Trust Score Algorithm

It generates a Trust Score (0–100) with visual dashboard representation.

---

## ⚙️ Tech Stack
- Python (Flask)
- SQLite
- Scikit-learn
- BeautifulSoup
- Chart.js
- HTML/CSS/JS

---

## 🧠 Scoring System
Final Score =
- 25% Text Analysis
- 30% Image Analysis
- 45% Behaviour Analysis

---

## 🚀 Features
- User Authentication
- URL Analysis
- ML-based Scam Detection
- Interactive Gauge Dashboard
- Risk Classification (Low / Medium / High)
